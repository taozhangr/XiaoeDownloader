# 小鹅通下载器

面向团队内部使用的小鹅通课程下载工具，只保留以下主流程：

1. 使用系统 Chrome 或 Edge 登录小鹅通 PC 学员端；
2. 粘贴课程、专栏或商家自定义域名链接；
3. 从当前账号的已购课程中识别课程并读取真实目录；
4. 选择内容，下载视频和课程附件。

项目不包含公众号登录、学豆、会员、机器码、自动更新或其他网课平台代码，也不会保存小鹅通账号和密码。

## 运行

在本目录执行：

```powershell
uv run main.py
```

首次启动会打开系统安装的 Google Chrome；未安装 Chrome 时使用 Microsoft Edge。浏览器登录状态保存在当前 Windows 用户的 `XiaoeDownloader` 数据目录中，后续运行通常无需重复扫码。

下载结果默认位于项目的 `downloads` 目录，并按课程名称建立子目录。已存在且非空的文件会直接跳过。

## 支持范围

- 支持小鹅通公共域名及商家自定义域名，例如 `www.pnxuetang.cn`。
- 专栏目录通过小鹅通业务接口读取，不扫描页面中的推荐课程或链接。
- 视频播放地址通过 PC 学员端接口获取，支持普通 HLS 和小鹅通 PC 客户端使用的 AES-128 私有 HLS。
- 下载时统一显示百分比、已下载大小、实时速度和预计剩余时间。
- 课程附件会和目录内容一起显示，用户可按编号选择。
- 当前下载实现以视频专栏和直链附件为主；遇到图文、直播、练习等尚未移植的资源类型时会明确提示并跳过。
- 只处理当前登录账号出现在 PC 已购课程列表、且接口仍授权返回播放信息的内容；不绕过小鹅通账号权限或 Widevine/FairPlay/PlayReady DRM。

## 其他命令

```powershell
uv run main.py --check
uv run ruff check .
uv run ruff format --check .
```

程序调用的是系统浏览器程序，但使用独立的自动化配置目录；这是为了稳定读取本程序登录产生的 Cookie，并避免占用或修改用户日常浏览器配置。
